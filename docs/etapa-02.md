ETAPA 02 — PROTÓTIPO ESTRUTURAL COM HTML SEMÂNTICO

1. Funcionalidades implementadas

- Página inicial com visão geral do sistema.
- Listagem de campanhas.
- Formulário para cadastro de campanha.
- Navegação entre as páginas.

2. Páginas criadas

- index.html: página inicial.
- campanhas.html: listagem das campanhas.
- cadastro-campanha.html: formulário de cadastro.

3. Decisões relacionadas à estrutura HTML

Foram utilizados elementos semânticos como header, nav, main, section, article, form, label, button e footer.

Os campos do formulário possuem labels associados através dos atributos for e id.

Os arquivos HTML foram organizados na pasta src e o arquivo CSS na pasta src/css.
